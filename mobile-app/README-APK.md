# الحصول على تطبيق أندرويد (APK)

لم أستطع بناء ملف APK جاهز بنفسي هنا: بناء تطبيق أندرويد يحتاج أدوات
Google الرسمية (Android SDK وGradle)، وهذه الخوادم محجوبة في بيئة
التنفيذ التي أعمل بها حاليًا. لكن كل شيء جاهز ليُبنى تلقائيًا **مجانًا
عبر GitHub خلال دقائق**، بدون تثبيت Android Studio على هاتفك.

## الخطوات

1. ادفع مجلد `jawan-delivery` (المجلد الرئيسي كاملًا، وبداخله هذا
   المجلد `mobile-app`) إلى مستودع (repo) على GitHub — عبر `git push`
   من Termux أو موقع GitHub مباشرة.
2. بمجرد الدفع، سيعمل ملف `.github/workflows/build-apk.yml` تلقائيًا
   (تبويب **Actions** في صفحة المستودع على GitHub).
3. انتظر انتهاء العملية (عادة 3–6 دقائق)، ثم افتح تشغيلة العملية
   (run) الأخيرة، وستجد ملف APK جاهزًا للتنزيل تحت قسم **Artifacts**
   باسم `jawan-delivery-debug-apk`.
4. نزّل الملف، فك الضغط عنه (ستجد بداخله `app-debug.apk`)، انقله إلى
   هاتف أندرويد، وثبّته (فعّل "السماح بالتثبيت من مصادر غير معروفة"
   إذا طلب النظام ذلك).

## ملاحظات مهمة

- هذا **APK تجريبي (debug)** موقّع بمفتاح Gradle الافتراضي — يعمل
  تمامًا لتجربة التطبيق والتوزيع اليدوي، لكنه غير مناسب للنشر على
  Google Play (ذلك يحتاج توقيعًا برمز إصدار release خاص بك، خطوة
  لاحقة إن احتجتها).
- ملفات الموقع (`index.html`, `css/`, `js/`, `pages/`, `assets/`)
  تبقى بمصدر واحد في المجلد الرئيسي؛ عند البناء ينسخها السكربت
  `sync-web.sh` تلقائيًا داخل `mobile-app/www` (هذا المجلد لا يُحفظ في
  git، يُعاد إنشاؤه في كل مرة). لا تُعدّل شيئًا داخل `www` مباشرة —
  عدّل الملفات الأصلية في المجلد الرئيسي فقط.
- في كل مرة تدفع تعديلاً جديدًا على الموقع إلى GitHub، ستحصل تلقائيًا
  على APK محدّث بأحدث نسخة من الكود.
- إن أردت تشغيل هذا محليًا لاحقًا على جهاز فيه Android Studio: نفّذ
  `npm install` ثم `npm run sync` داخل هذا المجلد، ثم افتح `android/`
  في Android Studio.
